# 🌐 Vonas Media v2

A creative 3D web experience built as an experimental upgrade of Vonas Media, focusing on immersive UI, motion design, and interactive storytelling.

This project explores how digital content can exist as a **spatial experience rather than a static layout**.

---

## ✦ Overview

Vonas Media v2 is a creative lab for building:
- 3D interactive web scenes
- Motion-driven user interfaces
- Experimental layout systems
- Cinematic landing page experiences

It blends UI design, animation, and WebGL into a unified experience.

---

## ✦ Concept

Instead of traditional web pages, this project treats each section as a **scene**.

- Content becomes spatial
- Navigation becomes motion
- Interaction becomes experience

> CONTENT • CHANNEL • LAB

---

## ✦ Features

- 3D hero environment using React Three Fiber
- Smooth motion transitions with Framer Motion
- Layered UI with depth-based design
- Interactive elements (hover, focus, scene presence)
- Cinematic landing page structure

---

## ✦ Experience Direction

The design focuses on:
- Spatial composition instead of flat layouts
- Motion-guided attention flow
- Minimal UI interference with 3D visuals
- Immersive storytelling through interaction

---

## ✦ Tech Direction

- React
- React Three Fiber
- Three.js
- Framer Motion
- Modern CSS / UI styling system

---

## ✦ Design Philosophy

- Let motion define hierarchy
- Use depth as structure
- Keep UI minimal but expressive
- Blend interface with environment
- Treat scrolling as navigation through space

---

## ✦ Status

An ongoing experimental project focused on:
**3D UI × Motion Design × Interactive Web Experience**

---

## ✦ Note

This project is intended as a creative exploration and portfolio piece, not a production application.
